# Currency Converter

A simple and intuitive web-based currency converter that allows users to convert between various currencies with live exchange rates.

## Features

- Convert between any two currencies.
- Displays real-time exchange rates.
- Sleek, user-friendly interface.
- Flags representing countries next to their currency options.

## Tech Stack

- **HTML5** for structure
- **CSS3** for styling
- **JavaScript** for functionality (Fetch API)
- **Font Awesome** for icons
- **Flags API** for country flag images
- **Currency API** for live exchange rates

## How to Use

1. **Enter the Amount**: Input the amount you want to convert in the "Enter Amount" field.
2. **Select Currencies**:
   - **From**: Choose the currency you are converting from.
   - **To**: Choose the currency you want to convert to.
3. **Get Exchange Rate**: Click on the "Get Exchange Rate" button to see the conversion result.
4. **Real-Time Exchange Rate**: The converted amount and the live exchange rate will be displayed below the button.
